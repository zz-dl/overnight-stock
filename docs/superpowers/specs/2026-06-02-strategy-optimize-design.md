# 一夜持股策略参数优化 — 设计规格

**日期：** 2026-06-02

## 目标
扫描约 90 种参数组合，找出扣除真实交易成本后均收益最高的配置，更新到 app。

## 参数空间

| 参数 | 候选值 |
|---|---|
| 涨幅下限 | 3.0% / 3.5% / 4.0% |
| 涨幅上限 | 4.5% / 5.0% / 5.5% |
| 大盘最低涨幅门槛 | 0.1% / 0.3% / 0.5% / 1.0% |
| 超额倍数（股票涨幅 ÷ 大盘涨幅） | 1.0x / 1.5x / 2.0x |

共 3×3×4×3 = **108 种组合**

## 交易规则
- 买入：今日收盘价（对应 14:50 尾盘）
- 卖出：次日**开盘价**（对应 10:00 开盘后第一笔）
- 每日买入：通过条件的股票中，按涨幅从高到低取 **Top 10**

## 交易成本（每轮，0.10% 合计）
- 印花税 0.05%（卖出单边）
- 佣金 0.025% × 2（买卖各一次）

## 输出
1. Excel 新增工作表"参数扫描"，列出 108 种组合的：扣费后均收益、胜率、交易笔数、最优月
2. Top 5 最优组合高亮绿色
3. 最优参数写入 `backtest.py` 注释，更新 `app.py` 中对应的扫描阈值

## 测试验证
- 最优参数回测结果写入 Excel
- 月度分布验证（不能只靠某一月份撑起来）
- 与原始策略对比（基准：avg +0.04%，扣费后约 -0.02%）
