# 一夜持股推荐页增强 — 设计规格（阶段一）

**日期：** 2026-06-02

## 目标
在推荐页为每只候选股显示推荐理由和历史胜率预测，帮助用户判断今日操作质量。

---

## 1. 页面顶部：市场条件横幅

位置：扫描选股 Tab，紧贴现有 index-bar 上方（替换或增强）

内容：
- 今日大盘涨幅（已有）
- 所属胜率区间标注（如"0.5-1.0%优质区间"）
- 星期、5MA位置
- 综合历史胜率预估

颜色规则：
- 胜率 ≥ 52%：绿色背景（#0d2a1e）
- 胜率 45-52%：黄色背景（#2a1e0d）
- 胜率 < 45%：红色背景（#2a0d0d）

---

## 2. 每只股票卡片增强

在现有股票卡片底部新增两个区块：

### 推荐理由（文字说明）
最多 3 条，每条一行，对应通过的关键标准：
- "涨幅 X.X%，处于 3-5% 甜蜜区间"
- "超额大盘 X.Xx，个股有独立行情"
- "大盘今日涨 X.XX%，历史胜率区间 XX%"

### 胜率进度条
```
预估胜率 52%  ████████░░
```
进度条颜色与横幅一致。

---

## 3. 胜率计算逻辑（后端，基于历史回测数据）

基础胜率来自大盘涨幅区间（`/api/scan` 返回时计算）：

| 大盘涨幅 | 基础胜率 |
|---|---|
| < 0.5% | 38% |
| 0.5-1.0% | 54% |
| 1.0-2.0% | 43% |
| 2.0%+ | 47% |

叠加修正（每项为加减值）：

| 条件 | 修正 |
|---|---|
| 超额2.0-2.5x（最优区间） | +3% |
| 超额>4x（过热） | -5% |
| 周五 | +2% |
| 周一 | +1% |
| 5MA上方（已由扫描保证） | +0%（基准） |
| 大盘连涨≥3天 | +1% |

最终值 clamp 到 [30%, 72%]。
